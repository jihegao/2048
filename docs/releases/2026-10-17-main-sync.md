# 2026-10-17 production/main reconciliation

This release folds the October 16 production changes into the current main branch, retaining the room identity privacy rules already merged in PR #39.

Included production changes:

- Show the existing live arena for both 1v1 and 3v3 matches.
- Default room management to unfinished rooms, with filtering applied before pagination.
- Resolve historical animal logo IDs and missing logos to the existing nine SVG assets, including offline exports.

Room privacy remains enforced by the server: students receive their own full identity and masked peer identities; teachers retain full details. Tournament assignment names use the same masking rules. No database migration is part of this release.

## Reproduce and verify

1. Merge the synchronization PR after CI passes, then check out the resulting full main commit.
2. Run the repository checks and build from that commit. Use `wrangler.new-production.jsonc` for production packaging and preserve the existing production runtime bindings and secrets.
3. Record the full main SHA in the Cloudflare version annotations (`workers/commit_sha` and `workers/tag`) when publishing the built Worker and static assets.
4. Read back the candidate metadata before sending traffic to it. Confirm its database, Durable Object namespaces, runtime flags and asset headers match production.
5. Verify that GitHub main still points to the recorded commit and that the active Cloudflare deployment routes 100% to that version. Compare the deployed static resources and Worker module with the artifacts built from that commit.
6. Verify the actual production JavaScript and SVG assets in mobile and desktop browsers with mocked API fixtures. Run the Worker privacy regression tests against the same packaged module locally, without creating production students or rooms.

The older primary workspace contains unrelated uncommitted work. It is not the source of this release and must not be deployed over the reconciled main branch.
