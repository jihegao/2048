# 2048 计时与全屏棋盘设计稿

> 需求编号：R-012 / R-013
> 状态：待产品确认
> 版本：v0.2
> 更新日期：2026-08-28

## 1. 需求定义

1. 比赛房间和个人练习都显示计时，但计时区域只保留纯数字，不增加重复说明文案。
2. 比赛与个人练习增加全屏模式：上方状态栏只显示当前得分和计时，下方显示棋盘。

高保真页面见 [`/public/timing-design.html`](../public/timing-design.html)，可通过 Vite 构建后的 `/timing-design.html` 预览。

## 2. 设计决策

- 计时条可见内容只有 `MM:SS`；状态通过数字颜色、边框和无障碍名称表达。
- 比赛使用剩余时间：候场倒计时、比赛中倒计时、最后 60 秒警示、结束 `00:00`。
- 练习使用累计时间：新局 `00:00`，移动后持续累计，game over 后冻结。
- 全屏状态栏只保留两个数字槽位：当前得分｜计时；不显示导航、房间信息、同步信息、操作提示或辅助卡片。
- 计时数字使用等宽数字，秒数变化不会推动棋盘或状态栏布局。

## 3. 普通模式

### 3.1 比赛房间

位置：房间主体卡片上方、棋盘之前。计时区域只显示一个居中的数字。

| 状态 | 示例数字 | 视觉处理 | 操作限制 |
| --- | --- | --- | --- |
| 候场倒计时 | `00:03` | 橙色边框与数字 | 不可移动 |
| 比赛进行中 | `04:28` | 品牌紫 / 青色数字 | 可移动 |
| 最后 60 秒 | `00:42` | 红色数字、轻微呼吸提示 | 可移动 |
| 比赛结束 | `00:00` | 灰色、停止动画 | 不可移动 |

显示规则：

- `countdown` 根据 `startsAt` 与服务端当前时间计算。
- `live` 根据 `endsAt` 与服务端当前时间计算，归零后进入结束态。
- 客户端只负责显示，不能用本地计时器决定比赛结束或结算。
- 断线时保留最后已知数字，重连后按服务端快照校正；可通过无障碍名称传达连接状态，不在计时条增加可见文案。

### 3.2 个人练习

位置：成绩卡片和 4×4 棋盘之间。计时区域只显示本局累计用时数字。

| 状态 | 示例数字 | 视觉处理 |
| --- | --- | --- |
| 尚未移动 | `00:00` | 青绿色数字 |
| 练习中 | `08:42` | 青绿色数字持续更新 |
| 本局结束 | `12:06` | 灰色数字并冻结 |

显示规则：

- 练习初始化后显示 `00:00`；第一次有效移动后开始累计。
- 重新开始、刷新或离开页面时重置，不把未结束练习写入成绩。
- 触发 `game over` 后冻结最后一秒，不因保存成绩请求继续增长。

## 4. 全屏模式

### 4.1 进入与退出

- 普通页面标题区提供“全屏”入口；进入后浏览器全屏承载游戏区域。
- 浏览器不支持原生全屏时使用等价的全窗口布局，按 Esc 退出。
- 全屏状态不改变比赛截止时间、练习保存规则或棋盘操作逻辑。

### 4.2 信息层级

全屏画面固定为：

```text
                 当前得分  |  计时

                       4 × 4 棋盘
```

- 比赛显示本人当前得分和比赛剩余时间。
- 个人练习显示当前得分和本局累计时间。
- 状态栏只显示数值；颜色只作为辅助，不新增标签或状态句子。
- 隐藏应用导航、房间辅助信息、侧栏卡片、操作提示和服务端同步提示。
- 棋盘保持 1:1 比例并垂直居中；移动端优先保证棋盘完整可见。

## 5. 响应式布局

### 桌面端（≥ 821px）

- 普通模式：计时数字与棋盘同一列，最大宽度跟随棋盘。
- 全屏模式：状态栏与棋盘同宽，棋盘最大宽度 520px，按视口高度收缩。

### 移动端（≤ 620px）

- 普通模式：计时数字占满计时条并居中，不挤压成绩卡片或棋盘。
- 全屏模式：状态栏横向排列两个数字，棋盘宽度取视口可用宽度，不能产生页面级横向滚动。
- 数字区域保留稳定高度，使用 `font-variant-numeric: tabular-nums`。

## 6. 无障碍

- 可见界面只显示数字；计时器通过 `role="timer"` 和 `aria-label` 提供“剩余时间 / 本局用时”等语义。
- 全屏状态栏为分组，得分和计时分别提供无障碍名称。
- 动态秒数不逐秒触发屏幕阅读器播报；开始、结束和连接状态使用状态语义表达。
- 中英文只影响无障碍名称和页面操作入口，不改变计时数字布局。

## 7. 验收清单

- [ ] 比赛房间普通模式的计时区域只显示数字，且覆盖候场、进行中、最后 60 秒和结束态。
- [ ] 个人练习普通模式的计时区域只显示数字，新局从 `00:00` 开始并在 game over 后冻结。
- [ ] 全屏模式上方只显示得分数字和计时数字，下方为可操作棋盘。
- [ ] 全屏模式隐藏导航、辅助卡片、操作提示和同步提示；退出后恢复原页面布局。
- [ ] 桌面端、360×800 手机和 768×1024 iPad 均无横向溢出。
- [ ] 比赛截止仍由服务端绝对时间控制，设计层不引入新的客户端结算逻辑。
