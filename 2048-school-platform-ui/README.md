# 校园 2048 在线挑战平台 · 界面原型

这是一个可直接演示的高保真前端原型，覆盖学生端、教师端及比赛实况端。项目不依赖构建工具或第三方前端框架，解压后即可运行。

## 快速预览

### 方式一：直接打开

打开 `standalone-demo.html`，即可使用全部界面和交互。

### 方式二：本地静态服务器

在项目目录执行：

```bash
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080`。

## 演示入口

- 学生账号：学号 `20260108`，密码 `demo2048`
- 登录页也提供“学生端”和“教师端”快捷入口
- 教师端会显示“赛事管理”和“新建房间”等管理功能

## 已完成页面

1. 学生登录：预录入学号、密码显示切换、角色快捷入口
2. 首页概览：近期赛事、倒计时、个人数据、挑战模式、赛程与热门实况
3. 房间大厅：搜索、模式筛选、房间码加入、公开房间与教师建房
4. 单人练习：可实际操作的 2048 棋盘、实时得分、最高方块、移动次数和练习目标
5. 1v1 对抗：本人/对手实时比分、分差、比赛计时、对手状态和对局动态
6. 组队挑战：本人得分、队友得分、对手得分、团队总分、贡献率和实时同步状态
7. 排行榜：全校/年级/班级/团队维度，综合积分、最高分、胜率和团队贡献筛选
8. 比赛实况：班级总分、走势、观战人数、赛场动态和双方队员实时成绩
9. 教师赛事管理：赛事概览、比赛监控、服务状态、异常复核和待办事项
10. 响应式移动端：底部导航、触控方向键、移动棋盘、窄屏房间和排行榜布局

## 可交互内容

- 2048 支持方向键、WASD、移动端滑动及屏幕方向键
- 房间列表支持关键词搜索和模式筛选
- 六位房间码输入支持自动跳格和回退
- 教师可打开建房弹窗并提交房间配置
- 1v1、团队赛和比赛实况会模拟实时比分、计时和赛场动态
- 学生与教师权限菜单会按登录角色切换
- 排行榜范围和统计类型可切换

## 接入正式后端

当前原型中的身份验证、实时房间和比赛数据为前端演示状态。正式开发时建议保留现有页面结构和消息模型，替换以下边界：

```text
登录表单       -> POST /api/auth/login
房间列表       -> GET  /api/rooms
创建房间       -> POST /api/rooms
加入比赛       -> POST /api/matches/:matchId/join
排行榜         -> GET  /api/leaderboards
比赛结算       -> POST /api/matches/:matchId/result
实时比分       -> WebSocket /ws/matches/:matchId
```

Cloudflare 部署建议：

- 前端静态资源：Workers Static Assets
- HTTP API：Cloudflare Workers
- 学生、赛事和排行榜数据：D1
- 每个实时房间：一个 Durable Object
- 比分与房间事件：Durable Objects WebSocket
- 回放或导出文件：R2，可选

正式 WebSocket 消息建议只让浏览器提交操作，不直接提交可信分数：

```json
{
  "type": "move",
  "matchId": "T-03",
  "direction": "left",
  "sequence": 127
}
```

服务端广播统一比分快照：

```json
{
  "type": "score_snapshot",
  "remainingMs": 93211,
  "players": [],
  "teams": []
}
```
